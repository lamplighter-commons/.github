# Lamplighter Commons

Open-source tools and learning resources, shared freely.

Small, useful projects and notes from things we learn and build. Started by [Jingming Liang](https://github.com/eprogressing).

## Triangle Light Maze Solver

Created and maintained by [Jingming Liang](https://github.com/eprogressing), and featured here as part of our open-source collection.

An interactive way to explore dynamic programming. Build a triangular maze, light up its nodes, and find the path that collects the most lights.

**[Try it in your browser](https://www.jingmingliang2004.com/triangle-light-maze-solver/)** · [Source code](https://github.com/eprogressing/triangle-light-maze-solver)
